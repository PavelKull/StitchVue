| функция | left | right | ожидание | зачем |
|---------|------|-------|----------|--------|
| samePathList | `[]` | `[]` | true | пустые списки |
| samePathList | `[]` | `['a']` | false | длина |

| samePathList | `['a','b']` | `['b','a']` | false | порядок важен |
| samePathList | `['a']` | `['a','b']` | false | разная длина |
| samePathSet | `[]` | `[]` | true | пустые списки |
