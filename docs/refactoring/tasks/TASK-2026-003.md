## 3. Business invariants

Канонические пункты не отмечены (локальный UI chrome, не сессия/ФС/миниатюры).

Дополнительно для задачи — **сохранить семантику** (как в `GalleryPage.tsx` на `base_commit`):

| Поведение | Требование |
|-----------|------------|
| Peek / hover | `preferences.panelsPeekOnEdge`; верх: полоса `TOP_NAV_PEEK_ACTIVATE_DEPTH_PX`, `WINDOW_FRAME_TOP_PX`, dock, lane guard; низ: `TOOLBAR_PEEK_*` из `toolbarPeekGeometry` |
| Pinned | `topNavPinned` / `toolbarPinned` / `sidebarPinned` — при pinned нижний toolbar принудительно visible (`useEffect` ~1319–1323) |
| Overlay blocking | `overlayBlocksToolbarPeek` (viewer/settings/properties/confirm/unfavorite/restore mounted) — не регистрировать peek listeners; сброс `toolbarHideTimer` (~1325–1331) |
| Scrollbar guards | `data-scrollbar-obstacle`, `data-gallery-scrollbar`, `dataset.scrollbarDrag`, `TOP_NAV_LANE_GUARD_PX`, `toolbarPeekBlockedByScrollbar` |
| Скрытие нижней панели | задержка **400 ms** (`setTimeout` ~1373–1376) |
| Пустая галерея | верхний peek: `view.images.length === 0` → не показывать top nav (~1303–1305) |
| Очистка | каждый `useEffect` с `addEventListener('mousemove')` — symmetric `removeEventListener` в cleanup; `clearTimeout` при unmount и при overlay block |

Неподтверждённое поведение дублирующих `onMouseMove` в JSX (~4552–4593) — при этапе 5 сверить с window listeners; **не менять UX**, только убрать дублирование, если hook покрывает тот же результат.
