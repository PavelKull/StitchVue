### Инварианты scroll chrome (обязательны к сохранению)

#### `set_scrolling` (IPC)

| # | Инвариант |
|---|-----------|
| S1 | `invoke('set_scrolling', …)` только когда изменились `mode` **или** `ahead` относительно предыдущего состояния в `scrollModeRef` (как ~1574–1577). |
| S2 | При переходе в idle: `invoke('set_scrolling', { mode: 'idle', ahead: 0 })`. |
| S3 | Не вызывать `set_scrolling` из cleanup unmount, кроме отмены pending idle через `clearTimeout` (без лишнего idle IPC при размонтировании, если таймер не сработал). |
| S4 | Использовать `advanceScrollMode` из `scrollLoadMode.ts` без форка логики. |

#### Idle timer (`SCROLL_IDLE_MS` = 200)

| # | Инвариант |
|---|-----------|
| T1 | Каждый `reportScrollActivity` делает `clearTimeout(scrollTimer)` перед постановкой нового таймера. |
| T2 | По истечении таймера: если `scrollModeRef.current.mode === 'idle'` — **return без IPC** (как ~1580–1582). |
| T3 | Иначе: сброс `scrollModeRef` в `initialScrollModeState()` и один вызов idle IPC (S2). |
| T4 | На unmount hook activity: `clearTimeout(scrollTimer)`; observer disconnect в jump hook. |

#### Scroll jump (UI)

| # | Инвариант |
|---|-----------|
| J1 | `canScroll` ⇔ `max > 2`, где `max = max(0, scrollHeight - clientHeight)`. |
| J2 | `pointUp` ⇔ `canScroll && scrollTop > clientHeight` (в `syncScrollJump` — `node.scrollTop`; в activity — параметр `top`). |
| J3 | `syncScrollJump` и activity обновляют jump через **один** pure `computeScrollJumpState` (два call site сохраняются). |
| J4 | Effect grid (~1697–1714): при `orderedImages.length === 0` — `{ canScroll: false, pointUp: false }`; иначе `syncScrollJump` + `ResizeObserver`; deps: `orderedImages.length`, `directoryKey`, `layoutMode`, `rowsPerScreen`, `bottomOverlayReserve`, `syncScrollJump`. |
| J5 | `jumpGalleryScroll`: при `max <= 2` — no-op; `prefers-reduced-motion` → `behavior: 'auto'`. |

#### `scrollTopRef` и смена папки

| # | Инвариант |
|---|-----------|
| R1 | **`scrollTopRef` объявлен и сбрасывается только в `GalleryPage`** (`load()` ~1345–1348: `scrollTopRef.current = 0`, `scrollModeRef` → initial — если `scrollModeRef` перенесён в activity hook, сброс в `load()` вызывает **экспортированный reset** hook или остаётся в page через ref на hook state; предпочтение: **reset API hook** `resetScrollActivityForFolderChange()` вызывается из `load()` в том же месте, без перестановки строк относительно `begin_directory_session`). |
| R2 | `scrollRestore` token/top — только GalleryPage; семантика props grid не меняется. |

#### Bottom overlay
