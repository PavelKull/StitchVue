## 5. Rollback

1. Зафиксировать посторонние незакоммиченные изменения (`git stash push -m "other" -- path` при необходимости).
2. Откатить только файлы задачи: `git restore --source=<base_commit> -- path1 path2`.
3. Проверить `git status` и релевантные тесты из раздела 4.
4. Не использовать `git reset --hard` / `git clean` без явного запроса пользователя.

## 6. Уровень риска и проверки

| Риск | Минимум проверок |
|------|------------------|
| low | `--seal` → `--preflight` → diff → `--strict` + параметризованные тесты (+ typecheck при TS) |
| medium | + связанные модули, инварианты, **regression-guardian**, smoke по затронутым пунктам |
| high | + **code-auditor** до правок, сценарии ошибок/partial failure, guardian, обязательный ручной smoke |

Операции с ФС, SQLite, удалением/перемещением фото — **high**. Hooks/эффекты — не ниже **medium**.

Гейты: пользователь `--seal`; до записи `--preflight` (только approved); перед Write `--auth`; после `--strict`. Исполнитель не вызывает `--seal` и не переводит `draft` в `in_progress`.
