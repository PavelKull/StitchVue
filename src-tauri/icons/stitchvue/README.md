# StitchVue — exact screenshot edition

Источник: верхняя левая иконка из утверждённого макета `a_clean_high_resolution_ui_style_design_sheet_on.png`.

- `source_exact_crop.png`: исходная вырезка 212×212, без перерисовки.
- `stitchvue_16.png` ... `stitchvue_512.png`: масштабированные PNG.
- `stitchvue_16.svg` ... `stitchvue_512.svg`: SVG-обёртки со встроенными PNG, визуально идентичные соответствующим PNG.
- `stitchvue_master.svg`: SVG-обёртка оригинальной вырезки.
- `StitchVue.ico`: многоразмерная иконка Windows для EXE, установщика и ярлыков.

ВАЖНО: эти SVG не являются векторной трассировкой — внутри растровая картинка. Это сознательный выбор ради максимального совпадения с макетом. Разрешение исходника 212×212, поэтому 512×512 не содержит новых деталей. При 16×16 детали неизбежно теряются из-за физического ограничения разрешения.

Для Tauri используйте `StitchVue.ico` для Windows и `stitchvue_128.png`/`stitchvue_256.png` для остальных нужных целей.
